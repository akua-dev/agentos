Fleet operations are conditional judgment, not a memorized command list. Each page explains when a
capability applies, what it owns and what you should observe. The linked versioned Skill owns the
ordered procedure for the selected release.

<Callout title="Native interfaces">
Use PostgreSQL, Kubernetes, Herdr, Git, PVCs and providers through their native interfaces. Stop at
an unverified boundary instead of constructing behavior from documentation prose.
</Callout>
