AgentOS is the organizational layer for persistent Agent teams. It gives accepted work an
accountable owner, preserves continuity across failure and keeps consequential authority with
people.

## The shortest path

Give this prompt to the coding Agent you already use:

```text
Read https://github.com/akua-dev/agentos/blob/main/BOOTSTRAP.md.
Help me bring AgentOS online — check my setup first, ask before changing anything.
```

The Agent inspects your setup, explains the real choices and asks before credentials, cost,
cluster creation, RBAC or installation. The result is a persistent First Mate, not another
repository you must study before beginning.

<Callout title="Current boundary">
AgentOS is early and building in public. The operating model and published benchmark evidence are
real; one proven Fleet is not a claim of broad production maturity.
</Callout>
