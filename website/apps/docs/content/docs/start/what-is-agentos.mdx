AgentOS is the open-source company harness. A coding harness turns a model into an Agent that can
own a bounded outcome. AgentOS gives multiple persistent Agents the organization required to work
as a company: durable identity, accountable ownership, explicit supervision, human authority and
recovery.

It is not a model, coding Agent, swarm, workflow builder, issue tracker or universal control plane.
You keep the models, harnesses, repositories, provider workflow and infrastructure you trust.
AgentOS connects those authorities without copying them into a proprietary world model.

## Who it is for

AgentOS is for a person or team that wants delegated work to continue without becoming a relay
between chat sessions. The Captain sets purpose and boundaries. First Mate turns intent into owned
work and returns only consequential decisions. Second Mates own durable domains; Crewmates deliver
bounded work.

“Autonomous” means the operating loop continues inside human-set boundaries. It does not mean
purpose, accountability or consequential authority disappeared.

## Current maturity

The project is early. It publishes benchmark attempts with their failures and evidence instead of
turning one successful demonstration into a general production claim. Begin with one project,
inspect what happens and widen authority only after the Fleet earns it.
