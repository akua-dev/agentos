## Learning has trust boundaries

Learning has several layers:

- private Mate memory recalls fallible preferences and context;
- project instructions preserve project-intrinsic facts through normal review;
- Fleet learnings record reviewed organizational knowledge;
- evaluation freezes behavior evidence;
- improvement changes the smallest owning source and retests it.

Memory is not authority. A remembered preference cannot override current SQL, Git, provider state
or human approval.

## Improve from frozen evidence

The interrupted checkout worker resumed successfully, but the evaluation reveals that its first
supervision wait had already completed and was not re-armed. The run remains frozen with that
failure.

Improvement finds the smallest cause in the supervision contract, writes a regression test and
changes the owning Skill. It reruns the original and a held-out recovery scenario before the
behavior becomes shared guidance.

Separately, the payments Second Mate may remember that this project’s compatibility suite often
reveals date-normalization assumptions. That context can shape a future brief, but the current
tests still decide whether the fact applies.
