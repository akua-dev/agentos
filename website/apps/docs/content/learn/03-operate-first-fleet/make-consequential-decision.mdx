## Ask for one exact choice

A consequential question is a durable speech act with a stable key, exact body and explicit
dependencies. The originating investigation can finish while the decision remains open.

First Mate presents the human meaning:

- what became known;
- which options are real;
- what each option changes;
- the exact choice requested.

Internal hold IDs stay out of the human question unless needed for diagnosis.

## Scope merge authority

The onboarding pull request is green. The project normally requires a human merge. You decide:

> Approve merge of this exact onboarding validation pull request after its current required checks
> remain green. This does not grant standing merge authority.

The exact answer is recorded. Only dependent work for that decision is released. A different pull
request, a later force-push or a production deploy is outside the scope.

Alternatively, you can record a narrow standing rule for a well-understood repeatable class. The
rule must name its constraints and consequences. Vague “handle routine changes” language is not a
safe authority contract.

Reading, acknowledging or discussing the question does not resolve it. The released database
Function couples the answer with local Task state.
