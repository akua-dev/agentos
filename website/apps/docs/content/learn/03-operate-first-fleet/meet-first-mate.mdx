## One company-facing interface

First Mate is the Captain’s regular interface to the Fleet. At every session start it reconciles
its identity, current bearings, unresolved decisions, accepted work and direct reports from native
authorities. Conversation history helps, but it is not the operating state.

First Mate does not normally edit project code. Its job is to preserve the supervision loop,
delegate to the right domain or bounded worker and return only outcomes, material risk and
consequential decisions.

## Return after a day

You reconnect and ask, “What is moving?”

A useful First-Mate response leads with human meaning:

> The onboarding validation pull request is ready and green. The checkout defect is still in
> diagnosis. One decision needs you: whether the compatibility change may include a production
> migration.

Agent IDs, pane handles and wait tasks stay in evidence unless needed for diagnosis. You can attach
to any relevant terminal when you want detail.

Behind the short answer, First Mate reconciled PostgreSQL, the provider and live runtimes. It did
not infer status from yesterday’s chat. The Captain role can be held by a person or team without
either maintaining the internal hierarchy.
