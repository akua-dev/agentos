## The project owns delivery

AgentOS adopts a project; it does not replace the project’s delivery contract. The closest
instructions, reviewed tools, tests, Git remote and provider workflow remain authoritative.

A remote-backed ship Assignment normally ends with:

- a clean committed task branch;
- proportionate project verification;
- branch push;
- the selected review artifact;
- a concise evidence report.

Merge is separate unless an exact decision covers it. A local-only project still needs its
declared clean committed branch; an uncommitted worktree is not review-ready.

## Pull request 128

The recovered onboarding worker completes compatibility tests and runs the project’s selected
no-mistakes workflow. That workflow reviews the diff, runs the required checks, pushes the task
branch and opens pull request 128.

First Mate reports:

> Onboarding validation is review-ready at pull request 128. Required checks passed. The change
> preserves the existing API; no migration remains. Merge is still yours.

The worktree is retained until Git and the provider prove the change is durably landed or a
deliberate handoff preserves it. A clean terminal or worker claim does not prove delivery.
