## The environment around the model

The model supplies inference. The harness supplies the operating environment around it:

- a native session and turn lifecycle;
- context loading and compaction;
- tools and sandbox;
- authentication and permissions;
- instructions and conditional Skills;
- model and reasoning selection;
- memory and recovery surfaces.

Pi and Codex are harnesses with different native behavior. AgentOS does not pretend their settings
are interchangeable, and an Agent is not defined by either one.

Instructions answer “who am I and what is always true?” Skills answer “what judgment applies in
this situation?” Deterministic code owns mechanics. Private memory recalls fallible context. Each
source keeps one job.

## Recovery rechecks reality

The onboarding Agent has edited two files and a long test is running. Its process disappears.

A durable harness can recover the same home, worktree and native session, then continue the same
outcome. It must also re-read Git and test state. A summary saying “validation was almost done”
cannot prove which files exist or whether the test passed.

If context pressure caused compaction rather than process loss, the same principle applies:
conversation memory is a cache. Reload current project instructions and authoritative state before
acting.
