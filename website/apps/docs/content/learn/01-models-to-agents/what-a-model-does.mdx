## Generation is not ownership

A model receives context and generates an output. It can explain, plan, classify or write code in
ways that feel like reasoning. But one inference has no durable goal, independent clock or
responsibility for what happens next.

```text
context + instructions
        ↓
      model
        ↓
generated output
```

Fluent output can be intelligent without being an actor. Continuity, authority and accountability
must come from systems around the model.

## A launch plan is still an answer

You ask:

> Draft a launch plan for a new onboarding flow. Include risks and a small first release.

The answer may contain excellent milestones and risks. You still decide whether to accept it,
preserve the plan, find an owner and notice when reality changes. If the browser closes, the model
has not abandoned an Assignment—there was no Assignment. It completed an inference.
