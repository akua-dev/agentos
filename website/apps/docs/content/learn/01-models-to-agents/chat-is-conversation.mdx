## The mental model

Chat wraps repeated model calls in a conversation. Earlier turns are assembled into later context,
so you can clarify, critique and progressively refine an artifact.

```text
human turn → model response → human correction → model response
```

This creates conversational continuity, not independent responsibility. The chat can remember the
launch plan while its context is loaded. The human still decides when to return, which new facts
matter and what action follows.

Long conversations also expose a limit: context is finite and fallible. A summary may preserve the
shape of earlier discussion while dropping a constraint. A chat transcript is useful history but
not the source of truth for a repository, production system or accepted organizational work.

## Worked example: refine the launch

Continue the previous chapter:

1. The model drafts an onboarding launch plan.
2. You explain that the company cannot change billing in the first release.
3. The model revises the plan around account creation and validation.
4. Tomorrow, analytics show a new failure mode.

The first three steps fit naturally in chat. Step four happens outside it. You must return with the
signal, recover the right context and decide whether the plan now needs work.

Chat reduces the effort of expressing corrections. It does not wake itself because production
changed, create an accountable owner or prove completion.

## What changes at this layer?

- Repeated generation becomes an interactive dialogue.
- Earlier turns can influence later output.
- Refinement becomes cheap and natural.
- The human still preserves the objective and decides each next action.
