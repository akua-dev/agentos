## Context creates a conversation

Chat wraps repeated model calls in turns. Earlier messages enter later context, so you can correct
an assumption and refine an artifact without restating everything.

```text
human turn → model response → human correction → model response
```

That is conversational continuity, not responsibility. The human still decides when to return,
which new facts matter and what happens outside the conversation. Context is also finite and
fallible: a summary may preserve the shape of a discussion while dropping one critical constraint.

## When the world changes

Suppose the model drafts an onboarding launch plan. You explain that billing cannot change in the
first release, and it revises the plan. Chat handles that correction naturally.

Tomorrow, analytics reveal a new failure mode. The chat does not wake itself, retrieve the signal
or decide who owns the response. You must return with the evidence and recover the right context.

A transcript is useful history, but Git still owns source, production owns live state and accepted
work needs a durable owner.
