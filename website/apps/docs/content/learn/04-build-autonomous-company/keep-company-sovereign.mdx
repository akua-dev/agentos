## Own the state; replace the interface

Sovereignty means people control the technology they create and depend on. The company’s durable
identity, work, homes and delivered source live in standard systems the operator can inspect,
self-host and replace.

Kubernetes keeps workloads, authorization and storage explicit. PostgreSQL holds durable
coordination. Herdr exposes native sessions. Git and providers hold delivery. No interface becomes
the only place the company knows itself.

## Replace the company surface

The support company begins with Discord as its human surface. Later it adopts a self-hosted
Buzz-like interface with searchable event history and ACP-connected harness sessions.

The migration should not rewrite Task identity, Agent homes or Git delivery. The new surface
submits intent to the same First-Mate boundary, reads approved organizational projections and
routes exact decisions. If it disappears, PostgreSQL and native authorities still preserve work.

<Callout title="Possible extension">
Buzz, Nostr, ACP, A2A, Argo, Electric, ClickHouse and OpenTelemetry are possible integrations, not
shipped core components. Adopt one only when it improves a proven boundary without creating hidden
authority or a mandatory hosted dependency.
</Callout>
