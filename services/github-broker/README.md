# AgentOS GitHub broker

The GitHub broker is the only AgentOS workload allowed to hold the Fleet GitHub
App private key or an upstream installation token. Native `git`, `gh`, and
`gh-axi` calls use the explicit HTTPS endpoint
`agentgateway-github.agentos.svc.cluster.local`; unrelated Internet traffic
continues directly from Agent Pods.

```text
native GitHub client
  -> projected ServiceAccount token
  -> agentgateway-github (HTTPS PEP)
  -> agentos-egress-authz (TokenReview + OpenFGA)
  -> closed repository/capability grant
  -> github-broker
  -> exact-repository GitHub App token
  -> GitHub API or smart HTTP
```

The workload helper reads the kubelet-rotated token for every invocation. It
passes the value only through the native child environment, blocks `gh auth`
credential-management commands, and preserves native stdin, stdout, stderr and
exit status. Git uses a dynamic credential helper and an owned `insteadOf`
rewrite. Neither path places identity or provider tokens in argv, remotes,
credential stores, shell history, managed state, logs or responses.

The broker validates the closed grant before minting a credential, requests one
repository and one minimum GitHub App permission, strips workload and grant
headers, and streams the upstream response. A provider `401` invalidates the
cached token. REST and Git smart HTTP resources are derived from the path.
Repository-bound GraphQL reads are supported; opaque node-ID mutations fail
closed because the repository cannot be proven from a native request.

## Kubernetes inputs

[`kubernetes/`](./kubernetes/) expects these core-namespace resources:

- `Secret/agentos-github-app` with `app-id`, `installation-id`,
  `installation-owner`, and `private-key.pem`;
- `Secret/agentos-github-tls` with `tls.crt` and `tls.key` for the internal
  Service DNS name;
- `ConfigMap/agentos-github-ca` with the public `ca.pem` distributed to Agent
  workloads.

Only the broker Deployment references `agentos-github-app`. Agent workloads
mount the public CA and their audience-bound projected ServiceAccount token.
The TLS Secret mounts only into agentgateway. Secret material is not committed
or generated by Kustomize; the managed secret controller and rotation workflow
own those resources.

[`../agentgateway/kubernetes/github-values.yaml`](../agentgateway/kubernetes/github-values.yaml)
is the pinned Helm render input for standalone agentgateway v1.4.1. Kustomize
remains the production deployment authority under #96. The GraphQL route alone
allows a bounded 256 KiB authorization-body copy; REST and Git streaming are
not buffered for authorization.
